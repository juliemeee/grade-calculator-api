# Grade Calculator

Сервис считает накопленную оценку по предмету и подсказывает, какой балл нужно
получить за оставшиеся работы, чтобы выйти на желаемую итоговую оценку.
Создан для студентов, у которых оценка складывается из ДЗ, работ и экзамена
с разными весами.

## Возможности
- `/courses` — список предметов со схемой весов;
- `/courses/{course_id}` — веса одного предмета;
- `/grade/{course_id}?scores=hw1:8,hw2:9` — накопленная оценка по сданным работам;
- `/target/{course_id}?known=...&target_grade=8` — какой балл нужен за оставшееся,
  чтобы выйти на желаемый итог; если цель недостижима, сервис это сообщает.

Особенность: у «Дискретных и непрерывных структур» сумма весов даёт максимум 11,
но итоговая оценка не бывает выше 10 — сервис показывает и сырую сумму, и итог
с пометкой `capped`.
